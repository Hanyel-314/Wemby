## 图片要求

### 格式
- **推荐格式：** JPG/JPEG（文件更小，加载更快）
- **其他支持格式：** PNG, WebP
- **不建议：** BMP, TIFF（文件太大）

### 质量
- **分辨率：** 至少 72 DPI（网页显示）
- **文件大小：** 每张图片建议 100KB - 500KB
- **色彩：** RGB 色彩模式

### 优化建议
为了更好的网页性能，建议压缩图片：
- 在线工具：TinyPNG (https://tinypng.com/)
- 桌面工具：ImageOptim (Mac), FileOptimizer (Windows)

## 如何添加图片

### 方法1: 直接复制
1. 将图片文件重命名为上述文件名
2. 复制到 `/images` 文件夹
3. 刷新浏览器查看效果

### 方法2: 使用命令行
```bash
# 进入项目目录
cd /home/user/Wemby/images

# 复制图片（替换为你的图片路径）
cp /path/to/your/image.jpg wembanyama-profile.jpg
cp /path/to/draft.jpg wembanyama-draft.jpg
cp /path/to/debut.jpg wembanyama-debut.jpg
cp /path/to/scoring.jpg wembanyama-scoring.jpg
cp /path/to/defense.jpg wembanyama-defense.jpg
```

## 故障排除

### 图片不显示？
- 检查文件名是否完全匹配（区分大小写）
- 确认图片在 `/images` 文件夹中
- 检查文件扩展名是否正确（.jpg 或 .jpeg）
- 清除浏览器缓存并刷新

### 图片变形？
- CSS 已设置 `object-fit: cover`，会自动裁剪
- 建议使用推荐的图片比例

### 图片太大？
- 使用图片压缩工具减小文件大小
- 调整图片尺寸到推荐大小

## 更新图片

如果想替换图片，只需：
1. 删除旧图片
2. 添加新图片（使用相同文件名）
3. 刷新浏览器
